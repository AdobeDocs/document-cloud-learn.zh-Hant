# 報告並追蹤使用量

瞭解如何產生報告及追蹤交易使用情況。 這些報表可包含已簽署合約的百分比或簽署合約的平均時間等資訊。 產生報表和追蹤使用情況可讓您檢視檔案簽署流程。
