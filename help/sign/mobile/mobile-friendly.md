# 方便使用的行動裝置檢視

在行動中完成工作不再是可選選項，從專業人士簽署合約，到家長填寫學校表格，對簡易行動解決方案的需求比以往任何時候都大。 瞭解如何使用行動裝置友好檢視，在行動裝置上完成表單時消除夾捏和縮放現象，並減少錯誤。

藉由「行動檢視」，Acrobat Sign讓任何人在行動裝置上填寫和簽署表單變得前所未有的容易，無論他們身在何處。 Mobile View透過在行動裝置上自動建立並提供簡化的UI，引導使用者完成必要的表單欄位，讓您透過以下方式更輕鬆有效且準確地完成檔案：

* 適合行動使用的欄位：不再需要夾捏和縮放，表單可完美配合熒幕
* 提高準確性：減少錯誤，並確保擷取所有必要資訊
* 持續性：使用者可隨時開始並返回適合行動裝置的表單，而不會失去進度
