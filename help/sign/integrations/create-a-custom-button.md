# 在Acrobat Sign中為[!DNL Salesforce]建立自訂按鈕

了解如何在 Salesforce.com 的標準物件中建立自訂按鈕。 在此範例中，自訂按鈕已新增到[!DNL Salesforce]中的&#x200B;**連絡人**。 按一下此按鈕後，它會開始傳送程式，並從&#x200B;**連絡人**&#x200B;直接將資訊填入合約中。
