# 建立和管理群組

瞭解如何建立群組、將使用者新增至群組，以及編輯群組設定。 群組可讓您擁有可存取不同物件庫檔案及不同設定（例如標誌與合作對象）的個別使用者子集。

>[!NOTE]
>
>群組僅適用於商務及企業級計畫。
