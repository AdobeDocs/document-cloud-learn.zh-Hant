# 在傳送之前編輯檔案和範本

每個工作流程都會包含最後一刻的變更。 在本教學課程中，瞭解如何直接在Acrobat Sign中更新檔案內容、取代影像並進行範本更正。

[此處](https://helpx.adobe.com/tw/sign/web/authoring/edit-agreement/new.html)提供完整功能的詳細資訊和限制。

>[!NOTE]
>
>檔案編輯必須由您的管理員啟用，更多詳細資料可在[這裡](https://helpx.adobe.com/tw/sign/web/settings-configuration/send-settings/edit-agreement.html)取得。
