# 識別侵蝕利潤來源偵測的轉包管理

主要合約層級不會失去專案利潤。 它一次只遺失一份轉包合約 — 變更訂單在所有人定價回收之前就增加了，RFI悄悄地變成延遲索賠，而合約保護從未變成子書。 當它出現在報表中時，錢已經花光了。 瞭解如何透過發現遺漏的變更單、過時RFI和合約差距，在影響專案獲利能力之前識別分包協定中的隱藏利潤流失風險。
