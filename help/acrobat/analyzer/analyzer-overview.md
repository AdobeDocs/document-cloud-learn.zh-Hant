# Acrobat Studio中的Analyzer概述

Acrobat Studio中的Analyzer可協助業務使用者從數以萬計的非結構化檔案中擷取結構化、可稽核的深入分析，以自動化以檔案為中心的業務流程。

## 新增功能

>[!TAB 開始使用]

[開始使用](get-started.md)瞭解如何從大量檔案中提取結構化、被引用的資料。

>[!TAB 使用集合]

瞭解如何隨著內容成長，建立手動和連結的[集合](collections.md)、套用屬性，以及保持檔案井然有序，
